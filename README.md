# Tai Network Landing Page

Marketing landing page for the Tai Network ecosystem.

## Overview

Static landing page showcasing:
- Tai Network infrastructure
- Tai Live streaming platform
- Tai Meet video conferencing
- Node operator program

## Tech Stack

- HTML5 / CSS3
- Vanilla JavaScript
- Three.js (3D background)

## Structure

```
Tai-Network-Landing/
├── index.html          # Main landing page
├── demo.html           # SDK demo page
├── download.html       # Node download page
├── styles.css          # Global styles
├── script.js           # Interactions & 3D background
└── assets/             # Images & logos
```

## Development

Simply open `index.html` in a browser, or use a local server:

```bash
# Using Python
python -m http.server 8000

# Using Node.js
npx serve .
```

Then visit `http://localhost:8000`

## Pages

| Page | Description |
|------|-------------|
| `index.html` | Main landing with hero, features, ecosystem |
| `demo.html` | Interactive SDK demo with video upload |
| `download.html` | Node operator CLI download |

## Deployment
